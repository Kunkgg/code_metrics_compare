# 08: 重复文件关联证据

**What to build:** 阅读者查看重复文件成员及两侧扫描内关系，理解重复文件数量变化并定位成员。

**Blocked by:** 03：文件完整查询与目录下钻

Status: ready-for-agent

依据：[正式产品化规格](../spec.md)及其中引用的最新 PRD／ARCHITECTURE。沿用 GLOSSARY 术语；本票编号采用用户确认的24票拆分，替代规格中12项里程碑的任务编号引用。

- [ ] 重复文件依据扫描内已确认内容 MD5 语义处理，按成员路径并集统计，不以文件名或重复行数替代。
- [ ] 两侧组关系分别展示，组号不作为跨版本身份；关联文件可进入文件详情并复制路径。
- [ ] 覆盖不同文件名／后缀、同成员多处引用、集合进出和无变化关系；完整分页无组大小截断。
- [ ] 正式报告的重复文件数量和成员关系通过 Golden 及独立预期，目录聚合与明细一致。
