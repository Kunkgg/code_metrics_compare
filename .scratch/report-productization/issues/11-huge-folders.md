# 11: 超大目录及扫描可见成员

**What to build:** 阅读者查看超大目录的清单进出、直接成员变化及扫描覆盖限制。

**Blocked by:** 04：可信输入与受限报告

Status: ready-for-agent

依据：[正式产品化规格](../spec.md)及其中引用的最新 PRD／ARCHITECTURE。沿用 GLOSSARY 术语；本票编号采用用户确认的24票拆分，替代规格中12项里程碑的任务编号引用。

- [ ] 目录直接成员为直接文件与去重直接子目录，不将全部后代文件作为直接成员；按各侧严格阈值判断超限。
- [ ] 成员证据支持按侧查看、完整分页和路径复制，展示新增／移出及总量不变的成员更替。
- [ ] 目录覆盖不足、扫描范围差异和根漂移显示限制，不能承诺完整磁盘成员或将未观测成员补零。
- [ ] 目录新增／退出超限与成员进出分别表达，保留原始／保留数量与完整关系。
- [ ] 通过超大目录 Golden、严格阈值及覆盖异常夹具，从正式入口到成员 UI 核对独立预期。
