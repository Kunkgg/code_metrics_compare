## 要回答的问题

用户难以理解每个分析页共用的“筛选与排序”，特别是“数值 / 最小值 / 最大值”。如何让阅读者直接表达“看哪类变化、先看谁、定位到哪里”，并保留必要的数值缩小范围能力？

用户补充：假设阅读者不了解相关业务背景，也应能只看页面理解功能的作用和用法。因此用途、术语、单位、执行方式和结果范围必须在页面就地说明。

## 本轮设计

- 延续已选择的概览与三栏分析布局，在同一原型内迭代。
- 目录树决定范围，表格持续显示实际路径与命中数量；路径与名称搜索即时生效。
- 依据明细类型提供可直接点击的变化类别；异常有独立入口与持续提示。
- 直接点击基线、当前、变化和标识表头排序，再点反向；文件/目录按路径，函数/危险调用按名称。当前排序持续可见。默认变化从大到小，选择减少或退出超限时，在按变化排序的情况下自动优先最大减少量。
- 普通数量列表提供“全部变化 / 只看增长 / 只看减少 / 全部对象”；超限列表改为新增/退出超限；存在性记录改为记录新增/消失或进入/退出重复清单。异常单独查看，筛掉异常时范围提示仍保留。
- 数值条件是可选操作，使用带单位的自然表达：基线值、当前值、增加量或减少量，配合“至少 / 不超过 / 介于”。增加与减少分别输入非负数量，区间两端包含边界。应用数值条件时切换到全部对象，避免沿用旧类别产生隐含冲突。
- 负数、空数量和倒置区间阻止应用并就地提示；取消编辑保留之前已应用的条件。
- 已应用数值条件可见且可单独移除；编辑中的条件只有点击应用才生效。
- 重复文件、危险函数和冗余块等存在性记录不展示 0/1 数值筛选；明细与右侧证据统一显示“有记录 / 无记录”和“新增 / 消失”。
- 解释代码行不计空行和注释、圈复杂度的含义、重复行数与重复率的区别、目录直接成员口径；解释基线/当前、超限严格大于阈值及两侧阈值不同的限制。
- 说明差值为零的记录也可能因位置、其他度量或关联变化而保留。空结果区分没有对象、没有变化和无匹配条件，并提供查看本范围全部对象的入口。
- 全范围筛选排序后分页；目录合计与均值/比例贡献仍按完整范围计算。

## Answer

筛选决定“留下哪些对象”，排序决定“先看哪个对象”。常用操作变为目录、即时搜索、变化类别和表头；数值条件用一句带度量与单位的话表达，作为可选的进一步缩小范围操作。

已实现并验证交互与数据一致性；尚未测量首次使用者的理解率或效率提升，需根据用户试用继续调整。页面：[生成的单 HTML](../../../output/prototype/cmetrics-prototype.html)。
