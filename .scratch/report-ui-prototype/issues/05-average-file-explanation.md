## 要求

均值与比例分析同时呈现分子、分母、指标的基线/当前及变化，说明分母的作用，并找出对变化贡献最大的对象。保留已有两组各十项入口。

| 指标 | 分子 | 分母 |
|---|---|---|
| 平均文件代码行 | 非空非注释代码行 | 总文件数 |
| 平均函数代码行 | 总函数代码行 | 总函数数 |
| 平均函数圈复杂度 | 总圈复杂度数 | 总函数数 |
| 代码重复率 | 总重复代码行数 | 非空非注释代码行 |
| 文件重复率 | 总重复文件数 | 总文件数 |
| 源代码重复率 | 源文件中的重复代码行总数 | 非空非注释代码行 |
| 源文件重复率 | 源文件中重复文件数 | 总文件数 |
| 超大头文件率 | 超大头文件数 | 总文件数 |
| 超大源文件率 | 超大源文件数 | 总文件数 |
| 超大函数率 | 超大函数数 | 总函数数 |
| 超大圈复杂度率 | 超大圈复杂度数 | 总函数数 |
| 超大目录率 | 超大目录数 | 总目录数 |

比例乘以 100%，差值与贡献使用百分点。均值使用行/文件、行/函数或复杂度/函数。全部小数保留两位，原始精度参与计算和排序。

## 实现

- 在指标导航与三栏明细之间增加“均值/比例变化与贡献”：分子、分母、指标的对比表；分子/分母的整体贡献；对象贡献列表。
- 默认解释全报告；选择目录后解释该目录及其后代。查询、状态筛选和明细分页不改变解释范围。
- 全报告保留原始汇总并核对明细；目录依据两侧各自的完整明细重算。总目录数包含所选目录本身及可见后代，全报告包含项目根目录。
- 文件贡献按合计贡献绝对值降序，正负作用均保留，每页 5 项，可翻页看完全部贡献对象；合计为零但分子/分母贡献不为零的抵消项仍保留。
- 函数类指标按文件聚合原始函数记录，避免同名函数配对影响总量解释。超大目录率按目录列出贡献。
- 源代码/源文件重复率的分母覆盖全部代码行/文件，因此贡献列表包含影响分母的头文件。
- 点击文件贡献精确限制到该路径，再查看文件或函数证据；非分子成员的分母贡献可进入文件代码行。目录贡献可进入目录文件明细。返回恢复指标、范围、查询与贡献页。
- 平均文件代码行额外列出存续文件变化、新增/移出文件的数量及代码行；超大率额外列出独立新增/退出超限。
- 未知数据、零分母、汇总冲突、阈值变化、目录成员或超限清单缺失时，不输出确定贡献和排名。受限超限进出显示“—”。
- 超大目录从完整可见文件树推导直接成员和超限集合，再双向核对报告清单，避免清单漏报被当作零。
- 支撑字段 `non_hfile_duplication_total` 的名称按本轮明确公式改为“源文件中重复文件数”。

## 分解口径

固定顺序：先保留基线分母，替换分子；再按当前分子调整分母。

设基线和当前分子为 N₀、N₁，分母为 D₀、D₁；均值倍率 k = 1，比例倍率 k = 100：

- 分子贡献：`(N₁ − N₀) / D₀ × k`。
- 分母贡献：`N₁ × (D₀ − D₁) / (D₀ × D₁) × k`。
- 两项贡献之和：`(N₁ / D₁ − N₀ / D₀) × k`。

每个文件或目录用自身分子、分母变化代入对应变化项，使用同一范围的分母及当前分子，因此对象贡献之和等于整体变化。这是固定顺序的算术分解，不表示已证明业务因果。口径说明默认折叠；分别四舍五入后显示值相加可能相差 0.01。
