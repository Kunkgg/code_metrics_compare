# 03: 文件完整查询与目录下钻

**What to build:** 阅读者在正式报告中按目录和条件定位文件，对完整结果排序分页并复制路径。

**Blocked by:** 01：最小离线报告：文件代码行变化

Status: ready-for-agent

依据：[正式产品化规格](../spec.md)及其中引用的最新 PRD／ARCHITECTURE。沿用 GLOSSARY 术语；本票编号采用用户确认的24票拆分，替代规格中12项里程碑的任务编号引用。

- [ ] 目录选择限定声明范围，路径搜索、数值条件、增长／减少／无变化筛选通过正式查询接口作用于完整结果集。
- [ ] 过滤、精确计数、稳定排序后分页；相同排序键有确定次序，首／深／末页及 50／51 页与独立全量序列一致。
- [ ] 目录层级聚合和文件列表保留未知及扫描集合进出来源，不将未知混入无变化或擅自补零。
- [ ] 默认保留全部文件明细，登记原始／保留数及零省略数；主线程仅接收当前页等有界结果。
- [ ] 路径可复制，界面显示当前范围、条件、数量及单位；复制失败给出可用提示。
- [ ] 通过正式构建产物和浏览器验证目录下钻、条件组合、跨页与复制；不以当前页匹配结果冒充全范围查询。
