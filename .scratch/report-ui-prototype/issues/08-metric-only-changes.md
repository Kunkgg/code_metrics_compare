# 08 按当前指标判定变化并精简页面文案

现行重建入口：在仓库根目录运行 `uv run python -m prototypes.ui.prototype --open`；源码位于 `prototypes/ui/`，指标名称位于 `docs/metric_names.md`，定向检查脚本位于 `scripts/prototype_checks/`。下文旧命令、源码路径及分支说明保留归档分支当时的记录。

## 要回答的问题

用户认为“位置等变化”难以理解，且页面不应有过多描述性说明。用户进一步明确：不再细拆位置和关联变化，对当前指标没有影响的对象统一标成“无变化”。

## 本轮设计

- 以当前明细列的基线与当前数值判定变化；数值相同显示“无变化”，仅位置、其他度量或关联关系变化的对象不进入“全部变化”。
- 未知、无法配对与不可比较保留异常状态，避免误标为“无变化”。
- 完整对象入口和原始详情继续可查；均值/比例汇总与贡献算法保持现有口径。
- 删去目录操作、用途介绍、变化口径、排序教程、版本术语和数值示例等常驻说明段落；保留当前范围、条件、数量、单位、阈值与异常信息。
- 延续已有三栏布局与筛选交互，直接迭代当前原型。

## Answer

变化标记只围绕当前明细指标表达：数值相同为“无变化”，数值不同保留增长、减少及相应进出标记；可靠性异常继续单独呈现。页面依靠控件名称、单位、数据和状态表达用途，常驻说明段落已移除。
