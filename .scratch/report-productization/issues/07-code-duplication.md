# 07: 重复代码关联证据

**What to build:** 阅读者从文件重复行变化进入两侧重复组、片段及关联文件，取得完整定位证据。

**Blocked by:** 03：文件完整查询与目录下钻

Status: ready-for-agent

依据：[正式产品化规格](../spec.md)及其中引用的最新 PRD／ARCHITECTURE。沿用 GLOSSARY 术语；本票编号采用用户确认的24票拆分，替代规格中12项里程碑的任务编号引用。

- [ ] 文件重复量按已确认度量参与变化与目录聚合；未知重复量保留限制，不用片段物理跨度反推有效覆盖事实。
- [ ] 两侧独立选组，不按跨版本组号配对；可查看片段开始行、长度、当前文件高亮及关联文件。
- [ ] 完整保留证据和跨块关系，大组、深页和末页查询无截断；复制位置包含可用侧别和定位信息。
- [ ] 当前指标无变化但关系或位置变化的记录仍保留，列表变化分类遵循当前指标口径。
- [ ] 用重复代码 Golden 和独立关系预期核对正式 HTML 中的结果、顺序、数量与定位。
