# 21: 正式 P3 变化与分布矩阵

**What to build:** 正式报告在全部目标变化分布中保持结果完整、正确且满足容量和交互硬门槛。

**Blocked by:** 20：正式 P2 业务验收

Status: ready-for-agent

依据：[正式产品化规格](../spec.md)及其中引用的最新 PRD／ARCHITECTURE。沿用 GLOSSARY 术语；本票编号采用用户确认的24票拆分，替代规格中12项里程碑的任务编号引用。

- [ ] 执行每侧100k文件／1m普通函数的1%／30%／100%变化 × mixed／wide／deep九组及集合进出组，补长字符串、高函数密度和近全量集合进出分布。
- [ ] 完整明细、顺序、总数、分页和关联证据与独立oracle比对；deep净影响执行直接有理数核验，不以间接结果替代。
- [ ] 逐数据集测量完整读入至发布的时间／内存、HTML体积、概览可操作和适用查询，不将小规模或其他分布数字外推。
- [ ] HTML≤200MiB，概览≤10秒，常用交互P95≤1秒，重操作P95≤3秒，浏览器新增峰值≤2GiB，完整生成≤10分钟且峰值≤8GiB。
- [ ] 冷、热口径分开，热任务至少20次，nearest-rank P95；确认每次真实发起查询，交互计时至DOM更新及后两帧。
- [ ] 保存输入／源码／依赖锁／HTML摘要、逐次样本、完整结果摘要、RSS和DOM证据；不再将localShortGatesMet=0表述为通过。
- [ ] 按实测固定块与缓存等参数，硬门槛失败停止关卡评审；不自动削减数据或改变单HTML交付。
