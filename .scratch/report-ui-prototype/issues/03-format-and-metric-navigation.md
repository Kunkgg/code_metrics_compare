# 03 显示精度、版本简称与指标分类入口

Type: prototype
Status: resolved

## 本轮要求

1. 所有小数四舍五入到两位。
2. 两侧统一称为“基线 / 当前”。
3. 页面文本不使用间隔点作为分隔符。
4. 分析指标从下拉框改为分类平铺。

## 实现

- 概览卡片、悬停提示、全部指标、分析数值与静态概览统一显示规则。均值、密度、比例固定两位并补足尾零；计数保留整数。
- `26.445` 显示为 `26.45`，`3.215` 显示为 `3.22`，`1.1%` 显示为 `1.10%`；微小差值显示为 `0.00`，不产生负零或正零符号。
- 仅格式化显示，原始数据精度、差值计算、增长判定、数值筛选和排序不变。很小的增长可能四舍五入显示为 `0.00`，仍保留增长标记。
- 两侧简称覆盖版本身份、表头、排序与数值筛选、详情、重复片段、目录覆盖提示及静态兜底。标题与其他分隔文本统一使用空格或 `/`。
- 分析页保留原有 12 个指标入口，根据用户后续反馈收敛为“常规指标 / 超大指标”两组，桌面端各占一行，不改变指标中文名称或统计口径。

| 分类 | 指标入口 |
|---|---|
| 常规指标 | 非空非注释代码行、总函数代码行、总圈复杂度数、总重复代码行数、总重复文件数、危险函数数、冗余代码数 |
| 超大指标 | 超大圈复杂度数、超大函数数、超大头文件数、超大源文件数、超大目录数 |

选中指标高亮并同步分析标题。按钮支持键盘操作，重渲染后保留焦点；重复点击已选指标保留现有查询。窄屏自动换行，全部指标入口仍可见。
