# 02: 内部真实输入契约核验

**What to build:** 内部人员在受控环境核验真实扫描契约，为正式 profile 适配提供明确、可追溯的依据。

**Blocked by:** None (can start immediately)

Status: ready-for-human

依据：[正式产品化规格](../spec.md)及其中引用的最新 PRD／ARCHITECTURE。沿用 GLOSSARY 术语；本票编号采用用户确认的24票拆分，替代规格中12项里程碑的任务编号引用。

- [ ] 登记代表性扫描器版本、结构与识别条件，核验字段类型、必填／可空、空容器、函数尾对象和行号规则。
- [ ] 核验比例序列化尺度、密度和零分母规则、危险函数去重、重复关系以及阈值含义；区分已证实事实与未关闭问题。
- [ ] 核验扫描范围、路径映射、大小写／分隔符处理及目录成员覆盖口径，不从单个样例推导所有版本行为。
- [ ] 输出非敏感结论、profile 映射依据及受控夹具的可用方式；真实数据、源码和报告留在内部，不要求外传。
- [ ] 明确支持候选版本和待补证据；本任务只确认输入契约，不替代正式产物的 P4 业务与性能终验。
