# 22: 正式 P3 长时与真实阅读验收

**What to build:** 阅读者在支持的真实桌面环境长期使用满规模报告，离线、资源和故障恢复行为均可核验。

**Blocked by:** 20：正式 P2 业务验收

Status: ready-for-agent

依据：[正式产品化规格](../spec.md)及其中引用的最新 PRD／ARCHITECTURE。沿用 GLOSSARY 术语；本票编号采用用户确认的24票拆分，替代规格中12项里程碑的任务编号引用。

- [ ] 登记具体macOS／Chrome、硬件、依赖与运行模式；执行headed和真实双击file://阅读，不以headless代替。
- [ ] 按PRD／架构规定的长时任务和适用分布执行会话，覆盖目录／指标切换、深页、净影响和证据查询，保存逐次行为与结果。
- [ ] 断网、初始化／Worker失败、重试、乱序及注入等在适用满规模数据上回归，记录专项数据集边界。
- [ ] 干净会话基线与进程树RSS采样测量新增峰值，包含页面和Worker，登记采样间隔、共享页及漏采局限，不只看JS heap。
- [ ] 记录实际DOM行标识并与独立预期核对，补齐原型DOM与RSS证据缺口；长时无持续泄漏、错误状态或必要结果丢失。
- [ ] 浏览器新增峰值≤2GiB，适用交互满足既定时延；工具通道失败单独归档，不拼接中断长时样本或掩盖产品失败。
- [ ] 形成独立P3阅读验收结论；若发现改动影响21已验收结果，重新验证受影响数据集。
