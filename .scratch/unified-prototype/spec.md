## 测量约定

- HTML ≤200 MiB；可操作 ≤10 s；常用交互 P95 ≤1 s；重搜索 P95 ≤3 s；浏览器新增峰值 ≤2 GiB；完整报告生成 ≤10 min／8 GiB。
- 规模、存续修改、集合进出、保留比例分别登记。1%、30%、接近／达到 100% 变化以及大量集合进出独立成组。
- 热查询每任务至少 20 次，nearest-rank 计算 P95；保存每次样本。完整结果检查失败的任务，不计作性能通过。
- 冷查询与热查询分开；干净浏览器启动不等于操作系统磁盘缓存已清空，后者未控制时明确登记。
- 交互覆盖页面请求至 DOM 更新及后续两帧，工具进程启动另计；已有容量 run 接口可作为其历史基线，不代表新 UI 的完整操作。
- 资源采样以独立浏览器空会话为基线，记录完整进程树 RSS 时间序列、增量、进程覆盖及采样间隔。RSS 共享页重复计数、漏采瞬时峰值等局限保留。
- 输入、HTML、源码与 uv.lock 保存 SHA-256；记录 CPU、物理内存、OS、实际浏览器版本、Python／Node／uv／agent-browser 版本、seed 和配置。
- 原始产物写 `output/unified-prototype/`；可版本管理的阶段结论写本目录 issues。原型源码／截图基线由 Git 提交和产物摘要定位，不提交大体积生成物。
