# 14: 四项重复率的净影响分析

**What to build:** 阅读者对代码重复率、文件重复率、源代码重复率和源文件重复率查看净影响并下钻证据。

**Blocked by:** 07：重复代码关联证据；08：重复文件关联证据；13：三项均值的净影响分析

Status: ready-for-agent

依据：[正式产品化规格](../spec.md)及其中引用的最新 PRD／ARCHITECTURE。沿用 GLOSSARY 术语；本票编号采用用户确认的24票拆分，替代规格中12项里程碑的任务编号引用。

- [ ] 四项重复率由完整输入到净影响结果及 UI 贯通，复用已确认分解方式和目录范围语义。
- [ ] 源代码重复率分母仍为全部非空非注释代码行，源文件重复率分母仍为全部文件，不因名称改成仅非头文件。
- [ ] 净影响支持排序、完整分页和关联证据；关系按两侧扫描独立，不建立重复组跨版本身份。
- [ ] 未知重复量、零分母及覆盖限制不被补零或生成确定净影响；以独立有理数预期核对结果和守恒。
- [ ] 正式报告通过四项入口、净影响排名、证据下钻及返回行为检查。
