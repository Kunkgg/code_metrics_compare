# 24: P4 内部真实数据终验

**What to build:** 内部人员在受控环境使用正式交付候选核验真实输入语义、业务任务和性能，形成正式交付结论。

**Blocked by:** 23：固定版本交付包与内部验收流程

Status: ready-for-human

依据：[正式产品化规格](../spec.md)及其中引用的最新 PRD／ARCHITECTURE。沿用 GLOSSARY 术语；本票编号采用用户确认的24票拆分，替代规格中12项里程碑的任务编号引用。

- [ ] 使用23固定版本，在受控环境核验代表性真实版本的字段尺度、位置、扫描范围及profile适用性。
- [ ] 对真实输入核对数值、变化、身份歧义、阈值、覆盖限制和关联证据，完成PRD五项任务并登记预期依据。
- [ ] 在适用目标规模和参考环境核验完整生成、HTML体积、启动、交互及新增峰值内存，满足既定硬门槛。
- [ ] 原始数据、源码及报告留在内部，仅提供允许共享的版本、结果和证据摘要；保留可追溯内部记录。
- [ ] 阻断问题修复后重跑受影响验收，并确保最终结论对应实际交付版本；P4未通过不得宣称正式交付完成。
