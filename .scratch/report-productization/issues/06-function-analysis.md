# 06: 函数代码行与圈复杂度分析

**What to build:** 阅读者由指标下钻至目录、文件和函数，取得代码行与圈复杂度变化及可靠位置。

**Blocked by:** 04：可信输入与受限报告

Status: ready-for-agent

依据：[正式产品化规格](../spec.md)及其中引用的最新 PRD／ARCHITECTURE。沿用 GLOSSARY 术语；本票编号采用用户确认的24票拆分，替代规格中12项里程碑的任务编号引用。

- [ ] 函数代码行与普通圈复杂度从正式输入贯通聚合、编译、查询和展示，支持完整范围筛选、排序及分页。
- [ ] 可靠一一对应时展示逐函数原值与差值；同文件同名函数不按行号猜测配对，显示两侧记录、匹配歧义及同名函数集合变化。
- [ ] 尾对象与普通函数分离，函数代码行和圈复杂度最大值正确核对；空函数集合按既定规则处理。
- [ ] 保留两侧有效原值、扫描集合进出及未知来源，复制可用的侧别、路径、行号和名称。
- [ ] 通过函数代码行／复杂度 Golden 与歧义、尾对象、集合进出夹具验证正式报告，并核对匹配基数无多对多放大。
