# 19: 已核验真实 profile 的报告支持

**What to build:** 内部已核验版本的真实输入能够通过正式入口生成正确或明确受限的报告。

**Blocked by:** 02：内部真实输入契约核验；04：可信输入与受限报告

Status: ready-for-agent

依据：[正式产品化规格](../spec.md)及其中引用的最新 PRD／ARCHITECTURE。沿用 GLOSSARY 术语；本票编号采用用户确认的24票拆分，替代规格中12项里程碑的任务编号引用。

- [ ] 只依据02的证据注册版本与结构识别条件，映射字段、尺度、空值、尾对象、行号和覆盖规则到统一规范化契约。
- [ ] 自动识别不能唯一确定时提供明确诊断；显式两侧 profile 只能选择已注册且适用的映射。
- [ ] 受控夹具从正式输入到报告结果验证原值、诊断、匹配、可比性及位置；不能用模拟 profile 假定代替真实规则。
- [ ] 内部执行受敏感数据限制的检查，提供非敏感证据摘要；未知版本和未核验能力不声明支持。
- [ ] 适配引发的共用逻辑变化回归已有模拟 profile；本票不代替P4全业务和性能终验。
