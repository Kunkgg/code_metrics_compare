# 09: 危险函数与冗余代码定位

**What to build:** 阅读者从危险函数或冗余代码指标进入文件与具体位置，核对数量变化并复制证据。

**Blocked by:** 03：文件完整查询与目录下钻

Status: ready-for-agent

依据：[正式产品化规格](../spec.md)及其中引用的最新 PRD／ARCHITECTURE。沿用 GLOSSARY 术语；本票编号采用用户确认的24票拆分，替代规格中12项里程碑的任务编号引用。

- [ ] 危险函数按已确认去重位置计数，冗余代码按块计数；正式输入、聚合、查询和页面使用相同口径。
- [ ] 支持文件／目录范围、名称或路径查找、方向筛选、排序和完整分页，位置记录保留各侧来源。
- [ ] 对象存在但无问题、不在扫描集合及未知明确区分；不把问题记录退出宣称为真实修复。
- [ ] 可复制危险函数名称／行号、冗余块起始行及侧别；不可用位置明确说明。
- [ ] 通过两类 Golden 和去重、多重集合、扫描集合进出夹具核对正式报告与独立预期。
